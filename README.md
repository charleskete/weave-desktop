# Weave for Mac

Release downloads for the Weave desktop app, a signed and notarized window onto [app.weaveit.ai](https://app.weaveit.ai).

- **Download the latest build:** https://app.weaveit.ai/download
- Each release here carries the `.dmg` (versioned, and again as `Weave.dmg`), the updater archive `Weave.app.tar.gz` with its `.sig`, and the updater manifest `latest.json`.
- Installed apps check `https://app.weaveit.ai/desktop/latest.json` once per launch and update themselves.

The app's source lives in the private `weave-mark2` repository; its `Desktop release` workflow publishes here on every `desktop-v*` tag.
